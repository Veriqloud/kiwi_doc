# Contribution Guidelines

Thank you for your interest in contributing to this project! Your contributions help improve and advance our hardware, FPGA, and PCB systems' documentation.

## How to Contribute
- **Reporting Bugs:** Use the [issue template](.github/ISSUE_TEMPLATE.md) to report issues. 
- **Suggesting Enhancements:** Open an issue to discuss improvements.
- **Submitting Changes:**
  - If you don’t have write access, fork the repository, create a feature branch, and submit a pull request.
  - If you have write access, create a feature branch directly in the main repository and submit a pull request.

## Documentation Style
- Use clear, concise language.
- Follow the existing structure and formatting.
- Include code examples, diagrams, or screenshots where helpful.
- Update the table of contents if you add or move pages.

## Community
- Be respectful, inclusive, and constructive.
- Follow our [Code of conduct](CODE_OF_CONDUCT.md).
